HRHsofts Ubuntu: customized Ubuntu with HRHsofts apps

A ready-to-use Ubuntu 26.04.1 desktop with 10 HRHsofts apps, cloud drives in Files, nearby sharing and a refined desktop. The apps also install on any Ubuntu as .deb packages or from the terminal.

Install the apps on Ubuntu

Every app, in one command (it adds the signed HRHsuite repository, then installs the apps):

wget -qO- https://hrhsofts-repos.github.io/apt/install.sh | sudo sh

Choose apps, or add the HRHsofts desktop too:

wget -qO- https://hrhsofts-repos.github.io/apt/install.sh | sudo sh -s -- pdfviewer mediaplayer
wget -qO- https://hrhsofts-repos.github.io/apt/install.sh | sudo sh -s -- all

Already added the repository? sudo apt install hrhsofts-calculator works like any Ubuntu software. You can also download a .deb below and open it, or run sudo apt install ./hrhsofts-NAME.deb.

Offline installer for every component: HRHsofts-Suite-2026.11.09.run (24.0 MB, SHA-256 42ecb6b6de4be28d21d9cccff4fcc7cdf1827bc3d270319fb8282f5027c906a7). Run it with sh HRHsofts-Suite-2026.11.09.run.

Updates from Azure

Packages are served from a signed APT repository at https://hrhsuiteupdates.blob.core.windows.net/apt. When a new version is published it shows up in Software Updater, in each app's Check for Updates and in the catalog (updated 2026-11-09).

Questions

Which Ubuntu versions are supported?

Ubuntu 26.04 LTS and later on 64-bit PCs (amd64). The apps also come preinstalled on HRHsofts Ubuntu.

How do updates work?

The installer adds the signed HRHsuite APT repository hosted on Microsoft Azure. New versions appear in Software Updater with the rest of the system, inside each app under Check for Updates, and with sudo apt update && sudo apt upgrade.

Do the apps show up in App Center?

Yes. The repository publishes AppStream data, so after installing hrhsofts-updater the apps can be found in Ubuntu's software tools and with appstreamcli search hrhsofts.

Is the download safe?

Every package list is signed with the HRHsuite archive key and every file has a SHA-256 checksum. The ISO also has a published checksum and validation report.

How do I remove an app?

Open App Center, or run sudo apt remove hrhsofts-NAME, for example sudo apt remove hrhsofts-cleaner.

About

Download videos and music from websites, any file at full speed, and torrents. Downloader is part of HRHsofts Apps and is installed for every account on this computer, like the built-in applications.

Open HRHsofts Setup to add or remove it.

Screenshots

Install

From the terminal (adds the signed HRHsuite repository so Downloader keeps itself updated):

wget -qO- https://hrhsofts-repos.github.io/apt/install.sh | sudo sh -s -- downloader

If the repository is already set up, or on HRHsofts Ubuntu:

sudo apt install hrhsofts-downloader

Or download the .deb and install it with App Center or sudo apt install ./hrhsofts-downloader_1.2.3-1_all.deb.

About

Stay linked to official WhatsApp Web with native cut, copy, paste, undo and redo, file and image attachments, page search, zoom, full screen, downloads, an unread badge, click-to-chat links and preferences.

Chats, groups, communities, status, channels and account settings are provided by WhatsApp Web. Calls and other advanced features depend on WhatsApp and browser support. This is an independent HRHsofts wrapper, not an official WhatsApp desktop application.

Install

From the terminal (adds the signed HRHsuite repository so WhatsApp keeps itself updated):

wget -qO- https://hrhsofts-repos.github.io/apt/install.sh | sudo sh -s -- whatsapp

If the repository is already set up, or on HRHsofts Ubuntu:

sudo apt install hrhsofts-whatsapp

Or download the .deb and install it with App Center or sudo apt install ./hrhsofts-whatsapp_1.2.4-1_all.deb.

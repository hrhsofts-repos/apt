About

Take screenshots of the screen, an area, a window or a long scrolling page, annotate them, and record the screen with sound. Screen Capture is part of HRHsofts Apps and is installed for every account on this computer, like the built-in applications.

Open HRHsofts Setup to add or remove it.

Screenshots

Install

From the terminal (adds the signed HRHsuite repository so Screen Capture keeps itself updated):

wget -qO- https://hrhsofts-repos.github.io/apt/install.sh | sudo sh -s -- screencapture

If the repository is already set up, or on HRHsofts Ubuntu:

sudo apt install hrhsofts-screencapture

Or download the .deb and install it with App Center or sudo apt install ./hrhsofts-screencapture_1.3.3-1_all.deb.

What's new

Version 1.3.3 · 09 Nov 2026
  • Check for Updates in the main menu: new versions are downloaded from the HRHsuite update service and installed after one password prompt
  • A notification offers new versions automatically, at most once a day
Version 1.3.2 · 08 Nov 2026
  • Quitting or logging out during a recording keeps it: it is recovered at the next start
  • Discard while a recording is being saved no longer deletes it
  • Animated GIFs no longer run out of memory and are never left half-written
  • Open With and Save As never replace the original or another file
  • A screenshot whose folder cannot be made opens unsaved instead of being lost
  • Damaged settings no longer stop the window or the editor from opening
  • Trimming no longer hangs on damaged recordings, and Cancel stops it at once
  • Folder and file names with quotes can be recorded; the login item works with any path
  • New: --version and a manual page
Version 1.3.1 · 07 Nov 2026

Close exits the idle application, clears the closed-window reference, and preserves ongoing captures and other editor windows. Settings that cannot be saved are reported before closing.

Version 1.3.0 · 07 Nov 2026
  • Capture history includes Copy Image, Copy File, Copy File Path and Pin to Screen
  • Remove or clear history without deleting files, and restore cleared entries
  • Screenshot and recording notifications offer targeted clipboard actions
  • Unsaved screenshot notifications can copy the image while it remains available
  • Background Wayland clipboard failures are reported instead of silently ignored
Version 1.2.0 · 02 Nov 2026
  • Scrolling screenshots match page content even when scrollbars change
  • Automatic scrolling requests input permission when needed and waits for stable, fresh frames
  • Scaled displays use the correct selection and pointer coordinates
  • Failed alignment keeps the matched image and explains why capture stopped
  • Long captures retain less memory and stop at the editor-compatible 32,000-pixel limit

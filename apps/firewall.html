About

HRHsofts Firewall puts Ubuntu's firewall (ufw) in plain words.

  • One switch for protection, and clear defaults for incoming and outgoing connections
  • Home, Office and Public profiles, switched automatically when you join a network; new networks get a safe guess and a choice in a notification
  • Rules for apps, well-known services and ports, from the local network, anyone or one address
  • Blocked attempts from the last 24 hours, grouped by service, with one-click allow
  • Live connections of your apps
  • Changes ask for an administrator password; reading the settings and switching between the fixed profiles do not

Install

From the terminal (adds the signed HRHsuite repository so Firewall keeps itself updated):

wget -qO- https://hrhsofts-repos.github.io/apt/install.sh | sudo sh -s -- firewall

If the repository is already set up, or on HRHsofts Ubuntu:

sudo apt install hrhsofts-firewall

Or download the .deb and install it with App Center or sudo apt install ./hrhsofts-firewall_1.0.0-1_all.deb.

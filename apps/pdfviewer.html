About

Read, search, annotate, organize and print PDF documents. PDF Viewer is part of HRHsofts Apps and is installed for every account on this computer, like the built-in applications.

Open HRHsofts Setup to add or remove it.

Screenshots

Install

From the terminal (adds the signed HRHsuite repository so PDF Viewer keeps itself updated):

wget -qO- https://hrhsofts-repos.github.io/apt/install.sh | sudo sh -s -- pdfviewer

If the repository is already set up, or on HRHsofts Ubuntu:

sudo apt install hrhsofts-pdfviewer

Or download the .deb and install it with App Center or sudo apt install ./hrhsofts-pdfviewer_1.1.2-1_all.deb.

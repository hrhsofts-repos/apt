About

HRHsofts Remote Desktop connects you to Windows, GNOME and HRHsofts computers, and lets others connect to yours.

  • RDP through FreeRDP: a window that resizes with you, full screen, all monitors, scaling, shared clipboard, sound, microphone, your Home folder and printers, Remote Desktop Gateway and security options
  • VNC through TigerVNC, including view-only connections, and SSH terminals
  • Passwords kept in GNOME Keyring and never placed on a command line
  • Groups, favourites, search and .rdp file import
  • Finds HRHsofts computers on the network and wakes sleeping ones (Wake-on-LAN)
  • Share This Computer turns GNOME Remote Desktop on or off, sets the visitor sign-in and view-only mode, and shows the address and certificate fingerprint to connect with

Install

From the terminal (adds the signed HRHsuite repository so Remote Desktop keeps itself updated):

wget -qO- https://hrhsofts-repos.github.io/apt/install.sh | sudo sh -s -- remote-desktop

If the repository is already set up, or on HRHsofts Ubuntu:

sudo apt install hrhsofts-remote-desktop

Or download the .deb and install it with App Center or sudo apt install ./hrhsofts-remote-desktop_1.0.0-1_all.deb.

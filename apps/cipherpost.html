About

Your inbox. Your privacy. A calm, connected mail workspace by HRHsofts, bringing your existing email accounts, OpenPGP tools and attachment previews together.

CipherPost is a full-featured desktop email client for Ubuntu with built-in end-to-end encryption.

  • Works with Gmail, Outlook/Hotmail, Microsoft 365, Yahoo, iCloud, Zoho, Proton Mail Bridge and any IMAP, POP3 and SMTP provider
  • OpenPGP encryption and digital signatures, compatible with Thunderbird, Proton Mail and GnuPG
  • Automatic key exchange with Autocrypt, key lookup via Web Key Directory and keys.openpgp.org
  • Local mail cache encrypted with AES-256-GCM, passwords stored in the GNOME Keyring
  • Remote images and trackers blocked by default
  • Unified inbox, rich-text composer, address book, folders, search and offline reading

Install

From the terminal (adds the signed HRHsuite repository so CipherPost keeps itself updated):

wget -qO- https://hrhsofts-repos.github.io/apt/install.sh | sudo sh -s -- cipherpost

If the repository is already set up, or on HRHsofts Ubuntu:

sudo apt install hrhsofts-cipherpost

Or download the .deb and install it with App Center or sudo apt install ./hrhsofts-cipherpost_1.2.1-1_all.deb.

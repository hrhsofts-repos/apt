Notepad for Ubuntu

About

HRHsofts Notepad is a fast, modern editor for plain text, Markdown, scripts and configuration files.

  • Tabs, syntax highlighting for dozens of languages and live word and line statistics
  • Detects UTF-8, UTF-16, Windows-1252 and other encodings, and keeps Windows, Unix or old Mac line endings
  • Opens the text of RTF, Word (.docx) and OpenDocument (.odt) files
  • Find and replace, go to line, and a warning before closing unsaved documents

Install

From the terminal (adds the signed HRHsuite repository so Notepad keeps itself updated):

wget -qO- https://hrhsofts-repos.github.io/apt/install.sh | sudo sh -s -- notepad

If the repository is already set up, or on HRHsofts Ubuntu:

sudo apt install hrhsofts-notepad

Or download the .deb and install it with App Center or sudo apt install ./hrhsofts-notepad_1.0.0-1_all.deb.

About

One assistant for the whole HRHsofts suite. Use Claude by Anthropic in the cloud, or a local model with Ollama that keeps everything on this computer; Auto picks local when it is running.

  • Chat, with text files and pictures
  • Summarize, improve, translate and question your notes and documents from inside the apps
  • Your API key is kept in the login keyring; AI is off until you turn it on
  • hrhsofts-ai brings the same tasks to the terminal

Install

From the terminal (adds the signed HRHsuite repository so AI Assistant keeps itself updated):

wget -qO- https://hrhsofts-repos.github.io/apt/install.sh | sudo sh -s -- ai

If the repository is already set up, or on HRHsofts Ubuntu:

sudo apt install hrhsofts-ai

Or download the .deb and install it with App Center or sudo apt install ./hrhsofts-ai_1.1.0-1_all.deb.

# HRHsofts Ubuntu – customized Ubuntu and free Ubuntu apps

**Website:** https://hrhsofts-repos.github.io/apt/

* **HRHsofts Ubuntu 26.04.1** – a customized Ubuntu desktop ISO with every HRHsofts app preinstalled:
  https://hrhsofts-repos.github.io/apt/ubuntu.html
* **Ubuntu apps (.deb)** – Calculator, CipherPost, Cleaner, Downloader, Image Viewer, Media Player,
  PDF Viewer, Recorder, Screen Capture and WhatsApp, plus the HRHsofts desktop add-ons.

## Install on Ubuntu 26.04 or later

```sh
wget -qO- https://hrhsofts-repos.github.io/apt/install.sh | sudo sh                    # every app
wget -qO- https://hrhsofts-repos.github.io/apt/install.sh | sudo sh -s -- pdfviewer    # chosen apps
wget -qO- https://hrhsofts-repos.github.io/apt/install.sh | sudo sh -s -- all          # apps + desktop
```

The script installs `hrhsofts-updater`, which adds the signed HRHsuite APT repository on Azure
(`https://hrhsuiteupdates.blob.core.windows.net/apt`). Updates then arrive through Software Updater,
`sudo apt upgrade` and each app's *Check for Updates*; the apps also appear in Ubuntu's software tools
through the repository's AppStream data.

This site is generated by `build_site.py` from the HRHsuite website sources. The `dists/` and `pool/`
folders are the legacy repository kept for older installations.

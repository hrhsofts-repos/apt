Installing HRHsofts Ubuntu

The installer is Ubuntu's own; every HRHsofts component is already on the ISO.

  1. Start from the USB drive

    Write the ISO to a USB drive, plug it in and choose it in your PC's boot menu (often F12, F10 or Esc). Pick Try or Install HRHsofts Ubuntu; use safe graphics if the screen stays black.

  2. HRHsofts Ubuntu starts

    The HRHsofts logo shows while the live system loads. Nothing is changed on your disk yet.

  3. Choose your language

    The language is used by the installer and by the installed system.

  4. Accessibility

    Turn on a larger text size, high contrast, a screen reader or other aids if you need them.

  5. Keyboard layout

    Pick your layout and type in the box to check it.

  6. Connect to the internet

    Optional. With a connection the installer can fetch the latest updates and drivers.

  7. Try or install

    Choose Install HRHsofts Ubuntu, or Try to look around the live desktop first and start the installer later from the dock.

  8. Interactive or automated installation

    Interactive installation asks the questions below; automated installation reads an autoinstall file.

  9. Apps

    The HRHsofts apps and desktop add-ons are always installed. Default selection keeps the system lean; Extended selection adds more Ubuntu tools.

  10. Optimise your computer

    Third-party graphics and Wi-Fi drivers and media formats; recommended for most PCs.

  11. Disk setup

    Erase disk and install uses the whole disk. Install alongside keeps Windows or another system, and Manual installation lets you choose partitions. Encryption is under Advanced features.

  12. Encryption and file system

    Leave No encryption, or encrypt the disk with a passphrase or the computer's TPM chip.

  13. Create your account

    Your name, the computer's name, your user name and password.

  14. Time zone

    Detected from your location when online; pick it on the map otherwise.

  15. Review and install

    Check the summary, then select Install.

  16. Installing

    Copying and configuring takes a few minutes. You can keep using the live system meanwhile.

  17. Restart

    Select Restart now and remove the USB drive when asked.

  18. Sign in

    Enter your password on the HRHsofts Ubuntu login screen.

  19. Ready

    The desktop opens with every HRHsofts app. Updates for the apps arrive in Software Updater with the rest of Ubuntu.
